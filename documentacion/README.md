# CARACTERISTICAS BASICAS DE PYHON:
#
# Python es un lenguaje de alto nivel considerado de los mas versatiles para el uso dentro del area cientifica
# tiene por detras registros de grandes empresas como google, facebook, youtube o la NASA.
#
# - ES DE PROPOSITO GENERAL: NO TIENE UN USO ESPECIAL; IA, JUEGOS, WEB.
# - LENGUAJE DE ALTO NIVEL
# - LENGUAJE DE TIPADO DINAMICO
# - LENGUAJE ORIENTADO A OBJETOS: REFERIDO A UN ESTILO DE PROGRAMACION DONDE PORCIONES DEL CODIGO SE TRABAJAN A PARTIR DE OBJETOS
# ¿QUE SON LOS OBJETOS? SON APARTADOS MAS ESPECIFICOS DEL CODIGO QUE DESARROLLAN UNA FUNCION ESPECIFICA.
# - LENGUAJE INTERPRETADO: NO SE COMPILA A LENGUAJE MAQUINA DIRECTAMENTE SINO QUE TIENE UN INTERPRETE DETRAS QUE SE ENCARGA DE ESTO MISMO
# - MULTIPARADIGMA: NO SE LIMITA LA EXPORTACION DE UN PROYECTO A UN SOLO SO
# - CASE SENSITIVE: AL IGUAL DE JAVASCRIPT, EL PROGRAMA DISTINGUE LAS MINUSCULAS Y MAYUSCULAS POR LO CUAL
# EN PYTHON Y JAVASCRIPT: variable !== Variable
# 
# ¿POR QUE USAR PYTHON? 
# 
# 
# Eficiencia en Time-to-Market: Permite ciclos de desarrollo iterativo y prototipado rápido. ¿Gracias a qué? A su sintaxis declarativa y
# tipeo dinámico, lo que reduce drásticamente el boilerplate en comparación con lenguajes de tipado estático (como Java o C++).
# Ecosistema y Bindings de bajo nivel: Domina el ecosistema de Machine Learning y Data Science. ¿Gracias a qué? A su capacidad técnica 
# para actuar como "lenguaje pegamento" (glue language), utilizando integraciones robustas (APIs en C/C++) que permiten ejecutar cálculos 
# pesados a nivel de máquina bajo el capó (ej. NumPy, TensorFlow) mientras se mantiene la abstracción en Python.
#
# Mantenibilidad intrínseca: Reduce la deuda técnica a largo plazo y estandariza las revisiones de código (code reviews). ¿Gracias a qué? 
# A la estructuración forzada por indentación (bloques semánticos espaciales) y el cumplimiento de las normativas del PEP 8, reduciendo la
# carga cognitiva del desarrollador.
#
# Portabilidad de ejecución: El mismo código fuente puede ser desplegado en múltiples arquitecturas sin recompilación. ¿Gracias a qué? A 
# la abstracción proporcionada por el intérprete (máquina virtual de CPython) que compila a bytecode multiplataforma en tiempo de
# ejecución.
#
# Versatilidad Multi-paradigma: Permite escalar la arquitectura del software según el requerimiento exacto del dominio. ¿Gracias a qué? A
# su soporte nativo para programación orientada a objetos (OOP), imperativa, y características de programación funcional (funciones de 
# orden superior, cierres, expresiones lambda).
#

# Origen y Contexto Histórico
#
# Python fue creado por Guido van Rossum y lanzado oficialmente en 1991. Se desarrolló originalmente como sucesor del lenguaje ABC para
#  interactuar de forma nativa con el sistema operativo Amoeba. La motivación arquitectónica principal fue diseñar un lenguaje de 
# scripting de alto nivel que resolviera las deficiencias de manejo de excepciones de ABC, priorizando de manera estricta la legibilidad 
# de la sintaxis y minimizando el coste de mantenimiento bajo la premisa de que "el código se lee muchas más veces de las que se escribe".
